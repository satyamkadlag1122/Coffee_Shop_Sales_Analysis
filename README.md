# ☕ Coffee Shop Sales Analysis Dashboard

An interactive **Excel dashboard** designed to analyze coffee shop sales performance, customer footfall, product performance, order patterns, and sales distribution across different store locations.

## 📊 Dashboard Preview

![Coffee Shop Sales Dashboard](images/coffee_shop_sales_dashboard.png)

---

## 🎯 Project Objective

The objective of this project is to transform coffee shop sales data into an interactive and easy-to-understand dashboard that helps identify:

- Overall sales and customer footfall performance
- Sales trends by hour and month
- Product and category performance
- Order-size distribution
- Store/location performance
- Weekday order patterns
- Top-performing products based on sales

## 📈 Dashboard Analysis

### 1. Quantity Ordered Based on Hours

The line chart shows how the quantity of products ordered changes throughout the day.

- Orders increase significantly during the morning hours.
- The highest quantity is observed around **10 AM**.
- Orders gradually decline after the morning peak.
- A sharp decrease is visible toward closing hours.

### 2. Category Distribution Based on Sales

The dashboard compares sales contribution across different product categories.

| Category | Sales Contribution |
|---|---:|
| **Coffee** | **39%** |
| **Tea** | **28%** |
| **Bakery** | **12%** |
| **Drinking Chocolate** | **10%** |
| **Coffee Beans** | **6%** |

Coffee is the largest sales-contributing category.

### 3. Size Distribution Based on Orders

| Size | Order Distribution |
|---|---:|
| **Regular** | **31%** |
| **Large** | **30%** |
| **Not Defined** | **30%** |
| **Small** | **9%** |

### 4. Footfall and Sales by Store Location

The dashboard compares performance across:

- **Astoria**
- **Hell's Kitchen**
- **Lower Manhattan**

**Hell's Kitchen** records the highest sales among the displayed store locations.

### 5. Top 5 Products Based on Sales

| Rank | Product | Sales |
|---:|---|---:|
| 1 | **Barista Espresso** | **$91,406.20** |
| 2 | **Brewed Chai Tea** | **$77,081.95** |
| 3 | **Hot Chocolate** | **$72,416.00** |
| 4 | **Gourmet Brewed Coffee** | **$70,034.60** |
| 5 | **Brewed Black Tea** | **$47,932.00** |

### 6. Orders on Weekdays

The dashboard compares order activity across:

**Sunday → Monday → Tuesday → Wednesday → Thursday → Friday → Saturday**

This helps identify daily customer ordering patterns and high-activity days.

## 🚀 How to Use

1. Clone or download this repository.
2. Open **Coffee Shop Sales Dashboard.xlsx** in Microsoft Excel.
3. Use the **Month Name** slicer to filter sales by month.
4. Use the **Day Name** slicer to analyze weekday performance.
5. Interact with the charts to explore sales and customer patterns.
